Dot Detection

A two-interval forced-choice demonstration. One interval contains a white dot; the other is blank. Choose the interval in which you saw the dot.

Default 132 pixels/inch, calibrated using the 10-mm ruler check; verify on the device being used. Browser zoom should be 100%. A physical ruler check is recommended.

Dot diameters: 5 and 8 arcmin. Each is presented for 300 ms. A central numeral and a brief tone announce each interval, then disappear before the dot can appear. The gap between stimulus intervals includes the second cue. No trial-by-trial feedback.

The white bar should measure 10 mm with a physical ruler. Adjust the pixels/inch setting if necessary.

For curiosity/research only. This is not a diagnostic test and does not replace ophthalmic assessment. No eye tracking: successful detection does not prove foveal mediation.
